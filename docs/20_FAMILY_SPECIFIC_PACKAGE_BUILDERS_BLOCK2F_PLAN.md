# Block 2F - Family Specific Package Builders

This block adds structured reusable package builders for pump, filter, salt system, and automation families on top of the generic equipment package template system.

## Delivered in this slice
- builder catalog with family-specific starter profiles
- preview function for built package lines
- save reusable package template from builder
- Quote Workflow UI for builder-driven template creation
- tests covering builder catalog, preview, save, and apply flow

## Target outcome
Users no longer need to hand-enter every package line for common families. They can pick a family, choose a builder profile, enter an equipment label and price, and generate a reusable package template that flows into the same quote package workspace and FreshBooks path.
